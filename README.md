# Koupelní 2 - návrh aktualizace webu

Samostatný veřejný návrh k připomínkám. Původní web https://koupelni.hireal.cz/ zůstává beze změny.

Obsahuje náhledy vybraných skutečných fotografií, oddělené označené vizualizace a datovaný snímek veřejné nabídky. Ceny a dostupnost nejsou živě synchronizované; aktuální podmínky potvrdí prodejce. Video je zadáno ke střihu a zatím není vloženo.

Repozitář neobsahuje původní fotografické soubory, plné předávací archivy, soukromou korespondenci, přístupové údaje ani pracovní kontrolní podklady.
